# 0001. 公開先をCloudflare Workers、DBをCloudflare D1にする

- 日付：2026-10-30
- 状態：決定

## 何に困っていたか

出先のスマホからも使えるよう、自分用のアプリをインターネットに置きたい。費用はかけたくない。困った時にしか開かないので、何週間も使わなくても止まらない場所が要る。

## 決めたこと

Next.jsをCloudflare Workers（OpenNext）で動かし、DBはCloudflare D1にする。ORMは使わない。

## 比べたもの

- Supabase：無料で同時に動かせるのは2つまでで、すでにほかの商品で埋まっている。無料のプランは7日間使われないと休止するので、困った時に止まっている
- ORM（Drizzle等）を足す：表が2つなので、仕組みを増やさない方を選んだ

## その結果

- D1には、使わないと止まる・消えるという決まりが無い。無料の範囲は、1日に読み取り500万行・書き込み10万行、保存は5GBまで
- D1は外から直接つながらず、Workersの中からしか使えない。Supabaseの行ごとの権限（RLS）のような仕組みは無いので、守りはログイン（[0002](0002-login-with-cloudflare-access.md)）とサーバーでの確かめに頼る
- Workersの無料プランは、1回の計算時間が10ミリ秒まで（bousai-portalと同じ制約）
