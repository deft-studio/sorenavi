# 0002. ログインをCloudflare Access（メールに届く数字）にする

- 日付：2026-10-30
- 状態：決定

## 何に困っていたか

アプリを使えるのを自分だけにしたい。リポジトリは公開するので、許可する自分のメールアドレスをコードに書けない。

## 決めたこと

アプリの手前にCloudflare Accessを置き、許可した自分のメールアドレスだけを通す。ログインは、メールに届く数字（One-time PIN）で行う。

## 比べたもの

- ログインをアプリの中に作る：作る物と、守る所が増える。許可するアドレスも、別の秘密の設定に置く必要がある
- AccessのGoogleログイン：押すだけで入れるが、Google CloudのOAuthの設定が要る。ログインは1か月に1回ほどなので、手間の差はわずかと考えた

## その結果

- アプリはログインの仕組みを持たない。許可するアドレスは、Cloudflareの管理画面に置く
- ログインしたままでいられる長さは、Accessの設定で決まる（最長1か月）
- 無料で使えるのは50人未満まで。ほかの人に使ってもらうことにしたら、見直す
- iPhoneのホーム画面に置いたアイコンから開いた時に、ログインが保たれるかは未確認。iPhoneでは、ホーム画面のアプリとSafariとで、ログインの記録（cookie）が別々になる。作り始めのタスクで確かめ、だめならSafariのブックマークから使うか、ログインをアプリの中に作る形を考え直す
