# 0003. 説明書は、利用者が貼った公式のリンクでAIに渡す

- 日付：2026-10-30
- 状態：決定

## 何に困っていたか

AIに読ませる説明書を、どう手に入れるかを決める必要があった。説明書の著作権はメーカーにある。

## 決めたこと

利用者がメーカーの公式サイトで取扱説明書のPDFのリンクをコピーして登録し、アプリはそのリンクをそのままClaude APIに渡す（Anthropic側が取りに行く）。アプリは説明書を保存しない。

## 比べたもの

- 型番や写真から、アプリが自動で取ってくる：メーカーごとに別の作りが要り、サイトが変わると壊れる。パナソニックは、説明書の自動での取得を断っている
- PDFをアプリに入れて保存する：説明書の写しを自分のサーバーに持つことになる。リンクで読めないメーカーが出た時だけ、そのメーカーの分を考える

## その結果

- 説明書の写しを、自分のサーバーやリポジトリに置かずに済む
- メーカーがPDFの置き場所を変えると、リンクが切れる。その時は、登録を直す画面へ案内する
- Anthropic側が、実際にメーカーのPDFを取れるかは未確認。作り始めの最初のタスクで確かめる（確かめた中身は[tech-check.md](../tech-check.md)）
