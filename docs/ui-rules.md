# 画面の決まり（見た目・操作の統一）

sorenavi の画面ごとに見た目や操作がばらつかないよう、次の決まりにそろえる。新しい画面を作る時も、この決まりに合わせる。画面の絵は [design-spec.md](design-spec.md) の「画面設計」、全体の説明は [../README.md](../README.md) を参照。

困った時に、スマホを片手で、焦って使う画面なので、読みやすさと押しやすさを先に決める。

## ボタン

- 押す所は、高さ44px以上にする（片手で焦って押しても外さないため。[AppleのHuman Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/accessibility)）
- 家電の一覧の行は、行全体を押すと、その家電の登録を直す画面を開く。行の右に矢印を置く。「説明書を開く」は、行の中のボタンにする（「直す」と並べて押し間違えないため）
- 答えの「説明書を開く」は、下線の文字ではなく、答えの下のボタンにする

## 色

- 赤は、危ない時の警告と、取り返しのつかない操作（消す）にだけ使う
- 色だけで伝えない。危ない時の警告には、アイコンと「危険」の文字を付ける（[WCAG 2.2 1.4.1](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)）
- 文字と背景の濃さの差は、4.5:1以上にする。補助の灰色の文字も同じ（[WCAG 2.2 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)）

## 文字

- 文字はNoto Sans JP。本文は16px以上、補助の文字は14px以上
- スマホの入力欄の文字は16px以上にする（iPhoneが画面を拡大するため）

## 確認

- 家電を消す時は、アプリの中の確認パネルを挟む。ボタンは「やめる」と「消す」

## お知らせ・パネル

- 危ない時の警告は、答えより上に、帯で出す。帯の文字は16px以上
- 止まった時（回数・料金の上限、ログイン切れなど）のお知らせは、理由と、次にできることを1つずつ書く。打った質問は消さない

## 広い画面（PC）

- 幅768px以上をPCとする。スマホの下のタブの代わりに、上のヘッダーで「質問」「家電」を切り替える
- 中身は、真ん中の列に置く。列の幅は720px（登録・直す画面は560px）
